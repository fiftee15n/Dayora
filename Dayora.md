# **Dayora — Your Personal Everyday Life Manager**

Selected Project  
Full-Stack Web Application

**Tagline:** Make Every Day Count.

## **1\. Project Overview**

**Dayora** is a full-stack personal productivity and everyday life management application designed to help people organize their daily activities, manage personal finances, build healthy habits, and keep track of important events from one centralized platform.

In everyday life, people often use multiple applications, notebooks, spreadsheets, and reminders to manage different aspects of their routines. Tasks are managed in one place, expenses are recorded somewhere else, and important reminders or personal notes are easily forgotten.

Dayora aims to simplify this experience by bringing essential daily management tools together in a single, easy-to-use platform.

It acts as a personal digital assistant that helps users stay organized, understand their daily activities, monitor spending habits, maintain consistency in personal routines, and make better use of their time.

The application will feature a personalized dashboard where users can get an overview of their daily progress, upcoming activities, financial summaries, and personal habits.

## **2\. Project Objectives**

The primary objectives of Dayora are:

1. Provide a centralized platform for managing everyday activities.  
2. Help users organize daily tasks and manage their time effectively.  
3. Track personal income and expenses to improve financial awareness.  
4. Encourage consistency through habit tracking.  
5. Prevent users from forgetting important activities through reminders.  
6. Maintain personal notes and important information in an organized manner.  
7. Provide meaningful insights into daily productivity and spending patterns.

## **6\. System Architecture**

Dayora will follow a client-server architecture with a separate frontend, backend and database.

**Presentation Layer**

Next.js \+ TypeScript \+ Tailwind CSS

Dashboard · Tasks · Expenses · Habits · Notes · Calendar

HTTPS · REST API · JSON

**Application Layer**

Node.js \+ Express.js

Authentication · Validation · Business Logic · API Services

**Data Layer**

PostgreSQL \+ Prisma ORM

Users · Tasks · Transactions · Habits · Reminders · Notes

## **7\. Database Design**

The application will use a relational database structure.

The primary database entities will include:

| Entity | Description |
| ----- | ----- |
| Users | Stores user account information |
| Tasks | Stores personal tasks |
| TaskCategories | Organizes tasks into categories |
| Transactions | Stores income and expense records |
| ExpenseCategories | Stores financial categories |
| Budgets | Stores monthly spending limits |
| Habits | Stores user-defined habits |
| HabitLogs | Tracks habit completion |
| Reminders | Stores scheduled reminders |
| Notes | Stores personal notes |
| ActivityLogs | Records important user activities |

All personal records will be associated with their respective user accounts through foreign-key relationships.

## **8\. Security and Data Protection**

Security will be an important consideration throughout development.

* Passwords will be hashed using bcrypt.  
* Authentication will use secure HTTP-only cookies.  
* Backend APIs will validate incoming requests.  
* User-specific resources will be protected through authorization checks.  
* Database queries will use Prisma's parameterized query mechanisms.  
* Sensitive configuration will be stored in environment variables.  
* CORS and security headers will be configured.  
* Rate limiting will be applied to sensitive endpoints.  
* Users will not be able to access other users' personal records.
